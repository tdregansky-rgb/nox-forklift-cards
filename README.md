# Nox Metals operator permit cards

Public, phone-friendly permit cards for Nox Metals powered industrial truck operators (MIOSHA Part 21 / OSHA 1910.178).

This site is a static page. It looks up a card by `?id=` token and reads only the published **Card Data** feed (name, equipment, dates, evaluator, and status). It does not use `script.google.com`.

Examples:

- `https://tdregansky-rgb.github.io/nox-forklift-cards/?id=TOKEN`
- `https://tdregansky-rgb.github.io/nox-forklift-cards/?id=TOKEN&print=wallet`

To refresh printed QR codes after a URL change, run **Forklift Program → Set web app URL** (or paste this site’s base URL into Settings!B2) and **Make printable backup cards**.
